### Week 5 Objectives:

* Review and strengthen knowledge of AWS identity and access management.
* Learn AWS security and encryption services.
* Practice secret management and access monitoring.
* Enhance Amazon S3 security using AWS security services and VPC Endpoints.

### Week 5 Achievements:

* Reviewed and strengthened knowledge of IAM Users, Groups, Policies, and Roles, including access control using IAM Conditions.

* Learned how IAM Permission Boundaries limit the maximum permissions that can be granted to IAM users and roles.

* Practiced centralized identity and access management using AWS IAM Identity Center.

* Created and managed encryption keys with AWS KMS and encrypted data stored in Amazon S3.

* Monitored access activities using AWS CloudTrail and Amazon Athena while securely managing sensitive information with AWS Secrets Manager.

* Integrated AWS Secrets Manager with Amazon RDS and AWS Fargate to improve application security.

* Configured Bucket Policies, Block Public Access, AWS Config, Amazon Access Analyzer, VPC Endpoints, and VPC Endpoint Policies to enhance Amazon S3 security.

* Consolidated knowledge of IAM, KMS, Secrets Manager, and AWS security services to prepare for the project implementation phase.
