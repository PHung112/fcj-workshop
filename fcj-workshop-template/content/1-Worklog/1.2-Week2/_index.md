### Week 2 Objectives:

* Understand the core networking components in AWS.
* Practice building network infrastructure using Amazon VPC.
* Learn Site-to-Site VPN configuration and monitor resources with Amazon CloudWatch.
* Practice remote management of Windows and Linux EC2 instances.

### Week 2 Achievements:

* Understood the roles and functionality of AWS networking components, including Subnets, Route Tables, Internet Gateways, NAT Gateways, Security Groups, and Network ACLs.

* Successfully built and configured a basic network infrastructure using Amazon VPC.

* Deployed EC2 instances within a VPC and configured appropriate network security settings.

* Learned how to collect and analyze network traffic using VPC Flow Logs.

* Gained an understanding of Site-to-Site VPN configuration and basic VPN troubleshooting.

* Practiced remote administration of Windows and Linux EC2 instances using Remote Desktop and SSH.

* Used Amazon CloudWatch to monitor system performance and configure basic alerts.

* Reviewed and reinforced the networking and infrastructure knowledge acquired during the first two weeks.
