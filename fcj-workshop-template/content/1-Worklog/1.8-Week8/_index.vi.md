### Kết quả đạt được tuần 8:

* Hoàn thiện AWS Architecture Diagram và tối ưu kiến trúc hệ thống dựa trên yêu cầu triển khai thực tế.

* Thống nhất phương án phát triển, hoàn thiện thiết kế kiến trúc và chuẩn bị đầy đủ cho giai đoạn phát triển Backend.

* Thiết lập thành công môi trường phát triển và cấu hình các thành phần cần thiết cho dự án Backend.

* Hoàn thành việc phân chia nhiệm vụ giữa các thành viên theo từng module của hệ thống.

* Phát triển Site Service, xây dựng các API và triển khai các chức năng nghiệp vụ theo thiết kế.

* Tiếp tục hoàn thiện Site Service, thực hiện kiểm thử API và phối hợp tích hợp với các dịch vụ Backend khác.

* Phát triển Media Service và Notification Service, xây dựng API và xử lý nghiệp vụ theo yêu cầu của dự án.

* Tích hợp các module Backend, kiểm tra kết nối giữa các dịch vụ và hoàn tất công tác chuẩn bị cho giai đoạn phát triển Frontend.
